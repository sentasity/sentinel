# Security

If you find a vulnerability, please report it through
[GitHub's private vulnerability reporting](https://github.com/sentasity/sentinel/security/advisories/new)
rather than opening a public issue.

Sentinel holds credentials for Sentry, Microsoft Teams, GitHub, and Claude,
and it runs unattended sessions against a repository, so I'd rather hear
about a problem privately first. I'll acknowledge reports as soon as I can,
though I can't promise a timeline.

Please don't test findings against a deployment you don't operate.
