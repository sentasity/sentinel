# Your alerts arrive already investigated.

A new Sentry issue posts a card to Teams, then an unattended Claude Code session
checks your repository out at the release SHA, works out the root cause, and replies
in the thread. Findings that clear the confidence gate can open a pull request.
Nothing merges automatically.
